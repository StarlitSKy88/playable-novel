🔑 API 设置（BYOK 模式）

支持任何 OpenAI 兼容接口。Key 仅保存在你的浏览器本地，不会上传服务器。

快捷预设：

自动识别原著语言并以同语言续写；也可指定用其他语言叙述（中文原著 + 英文扮演）

开启后每个场景自动生成一张插画（缓存到本地 IndexedDB，不重复消耗）

💻 本地直用模式
未检测到 Node 后端：当前以纯静态页面运行，演示引擎已内置；配置 Key 后将由浏览器直连 API（需服务商支持 CORS）。
完整体验请运行 npm start。

📚 世界书 · 设定锁定

世界书条目会注入每次生成：常驻条目始终生效，触发条目在对话命中关键词时生效。AI 不得违背已锁定的设定。
