# 🎬 演示指南（评委 / 用户 3 分钟体验路径）

## 路径 A：零配置演示（无 API Key，30 秒上手）

1. `npm start` 后打开 http://localhost:3000
2. 点击 **「🎮 载入示例小说」** → 自动解析出 3 章
3. 点击 **「选择入口章节 →」** → AI 推演出「星海学院」世界卡片（演示模式）
4. 选择角色（默认：林辰）+ 点击「第一章 陌生的天花板」
5. 在输入框自由行动，例如：
   - `我握紧手背，默默运转那股热流`
   - `压低声音问苏璃：你刚才说印记，那是什么？`
   - `趁夜色翻窗而出，直奔旧图书馆`
6. 观察 DM 如何基于原文 + 你的选择续写剧情

## 路径 B：连接真实大模型（BYOK）

1. 点击右上角 **「🔑 API 设置」**
2. 填入任意 OpenAI 兼容接口（预设已内置 OpenAI / DeepSeek / 通义 / Kimi / Ollama）
3. 上传你自己的小说（.txt），体验完全由真实 LLM 驱动的互动叙事
