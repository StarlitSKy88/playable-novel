# 小红书小工具上传与大赛投稿指引

## 交付物

| 文件 | 说明 |
|---|---|
| `dist/xinghai-academy.xhs-tool.zip` | **要上传的就是这个**（20KB，纯离线） |
| `preview/` | 6 张界面截图（780×1688，3:4），可直接当小红书笔记配图 |
| `src/` | 源码，改内容后重新跑 `./build.sh` 即可再打包 |
| `check-story.js` | 剧情图校验（死链 / 线索 / 隐藏结局可达性） |
| `e2e.test.js` | 本地全流程回归（32 项断言） |

---

## 一、上传到小红书

> 前提：小工具功能目前仍在灰度放开中。若你的创作者后台没有「Builder Hub / 小工具」入口，需先在创作服务平台申请权限。

1. 打开 **小红书创作服务平台**：https://creator.xiaohongshu.com/new/red-app
   （用小红书 App 扫码登录，**个人创作者账号即可，无需企业资质、无需开店**）
2. 左侧进入 **Builder Hub → 小工具**
3. 点「创建工具」→ 上传 `dist/xinghai-academy.xhs-tool.zip`
4. 选择**版本号**和所需**权限**
   - 本工具**不需要任何权限**（不用相机、不选图、不上传），建议全部不勾
5. 提交安全与内容审核，通常几分钟到一天

### 如果上传后「部署失败」

| 原因 | 说明 |
|---|---|
| zip 里多套了一层目录 | 必须是解压后**顶层直接看到 `index.html`**。本包已按规范打包，直接传即可 |
| 用了内联脚本 / `onclick=` | 容器 CSP 禁止。本包脚本全部外置、事件全部 `addEventListener` |
| 引用了外部资源 | 本包零外部引用（已扫描确认），断网也能跑 |
| 文件类型不符 | 只允许 `.html/.css/.js/.png/.jpg/.jpeg/.gif/.webp/.svg/.woff/.woff2/.json` |

## 二、发布笔记并挂载小工具

审核通过后小工具还是「已发布但不可访问」状态，**必须发一篇笔记挂上去**：

1. 正常发布一篇笔记（图文或视频）
2. 编辑页找到 **「添加小工具」/ 组件板块** → 选中「星海学院的转学生」
3. 发布后，读者在**笔记下方**点开即可在 App 内直接玩，**不跳站、不用下载**

> 建议笔记方向：展示「4 种结局 + 5 条线索 + 隐藏结局」的收集玩法，比单纯介绍工具更容易拿收藏。

## 四、改内容后重新发布

```bash
# 1. 改 src/assets/story.js（剧情）或 src/assets/style.css（样式）
# 2. 校验剧情图
node check-story.js
# 3. 本地回归
NODE_PATH=/Users/opc-1/.workbuddy/binaries/node/workspace/node_modules node e2e.test.js
# 4. 重新打包
./build.sh
# 5. 后台小工具页面「更新版本」，重新提审
```

## 五、这个包里有什么

- **35 个剧情节点 / 49 个选项 / 2 种身份 / 4 种结局**
- 世界卡片 → 身份选择 → 章节入口 → 逐段浮现的互动叙事 → 分支结局
- 5 条线索收集，集齐解锁隐藏结局「守印者」（两条身份线都能集齐）
- 回溯、结局图鉴、进度本地保存（刷新可继续）
- 纯 CSS 夜色星海底图，**零图片资源**，总包 20KB

完整版能力（小工具沙箱不支持，只在网页主作品里）：导入自己的小说（txt/epub/png 角色卡）、调用大模型实时生成后续剧情、分层记忆、流式生成、世界书锁定、云端存档。
