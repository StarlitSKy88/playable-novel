# 📖 Playable Novel · 可玩小说引擎

> 把任何小说，变成一个你可以走进去的世界。
> **Leave the scripts behind. Your next adventure begins here.**

[![Node](https://img.shields.io/badge/node-%3E%3D18-brightgreen)]()
[![License](https://img.shields.io/badge/license-MIT-blue)]()
[![BYOK](https://img.shields.io/badge/AI-Bring%20Your%20Own%20Key-purple)]()

**Playable Novel** 是一个开源 AI 互动小说引擎：上传你自己的小说，AI 自动解析世界观与人物，你选择入口章节、决定扮演谁，然后**用一句话行动**，实时续写只属于你的剧情。

它不是聊天机器人，而是一位**随时候命的跑团主持人（DM）**——世界会记住你的每一个选择。

---

## ✨ 核心特性

| 特性 | 说明 |
|------|------|
| 📄 **任意小说导入** | 上传 `.txt` 或粘贴全文，自动按章节切分，无需预处理 |
| 🧠 **AI 世界推演** | 自动提炼世界观、核心人物、主角处境、故事风格与暗流伏笔 |
| 🎭 **自由扮演** | 扮演主角、原著角色、旁观者，或自定义任何身份 |
| ⚔️ **无剧本互动** | 没有固定选项，自由输入行动/台词，AI 基于原著设定续写 |
| 🧠 **分层记忆系统** | 近期对话逐字保留 + 旧对话自动压缩为「故事至今」摘要，长线剧情不失忆 |
| 🌊 **SSE 流式输出** | 打字机式实时生成，可随时停止；也可关闭以提升 prompt 缓存命中 |
| ✏️ **消息干预** | 编辑任意行动重写后续 / 重写某段剧情 / 回溯到任意历史节点 |
| 💰 **成本感知面板** | 实时 tokens 统计与费用估算（BYOK，花出去的每一分钱都看得见 |
| 💾 **IndexedDB 持久化** | 小说、进度、记忆体全部本地存储，刷新不丢失 |
| 🔑 **BYOK 模式** | 自带任意 OpenAI 兼容 API Key，零平台抽成，数据不经服务端 |
| 🎮 **演示模式** | 不配 Key 也能完整体验全流程（内置示例小说 + 本地模拟 DM） |

## 🚀 快速开始

```bash
# 1. 克隆仓库
git clone https://github.com/<your-name>/playable-novel.git
cd playable-novel

# 2. 安装依赖（仅 express 一个）
npm install

# 3. 启动
npm start

# 4. 打开浏览器
open http://localhost:3000
```

**零配置体验**：启动后点击「🎮 载入示例小说」，即可在演示模式下走完 上传 → 推演 → 互动 全流程。

## 🔑 连接你自己的大模型（BYOK）

点击右上角「🔑 API 设置」，支持任何 **OpenAI 兼容接口**：

| 服务商 | Base URL | 模型示例 |
|--------|----------|----------|
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| Ollama 本地 | `http://localhost:11434/v1` | `qwen2.5:7b` |

> 🔒 Key 仅保存在浏览器 `localStorage`，不经过任何第三方服务器。

## 🎮 玩法流程

```
上传小说  ──▶  AI 推演世界卡片  ──▶  选择入口章节 + 扮演身份  ──▶  自由行动，剧情实时续写
   📄              🧠                        🎭                          ⚔️
```

1. **上传**：拖入 txt / 粘贴全文（3000 字以上效果最佳）
2. **推演**：AI 生成「世界卡片」——世界观、人物关系、当前暗流
3. **入场**：从任意章节切入，选择你的身份
4. **互动**：像跑团一样描述行动，例如
   > 「拔剑挡在少女身前」
   > 「谎称自己是来自王都的使者」
   > 「悄悄握紧口袋里那枚发烫的徽章」
5. **续写**：DM 根据原著设定 + 你的历史选择，生成世界与人物的真实反应

## 🏗️ 技术架构

```
┌─────────────────────────────────────────────┐
│  浏览器 (原生 HTML/CSS/JS，零构建)            │
│  ├─ 章节解析 / AI 流式请求 / 演示模式          │
│  └─ IndexedDB：配置 + 小说 + 进度 + 记忆体     │
│     （localStorage 自动迁移 + 隐私模式降级）    │
├─────────────────────────────────────────────┤
│  Node.js + Express（唯一后端依赖）            │
│  ├─ /api/novel/split    章节智能切分          │
│  ├─ /api/ai/chat        OpenAI 兼容代理       │
│  ├─ /api/ai/stream      SSE 流式代理          │
│  └─ /api/ai/mock         演示模式生成器       │
├─────────────────────────────────────────────┤
│  任意 OpenAI 兼容 LLM（用户自带 Key）          │
└─────────────────────────────────────────────┘
```

**设计取舍**：
- **零数据库**：所有状态在浏览器本地（IndexedDB），部署只需 `npm start`
- **零前端框架**：单页原生 JS，复制即用，方便二次开发
- **无账号系统**：BYOK 模式天然不需要平台托管 Key

## 🧠 分层记忆系统

长线剧情失忆是 AI 互动叙事的头号痛点（OOC 用户 700 轮后仍抱怨 AI 遗忘）。我们的方案：

```
┌──────────────────────────────────────┐
│ 设定层   世界卡片（世界观/人物/暗流）      │  ← 始终注入
├──────────────────────────────────────┤
│ 摘要层   「故事至今」滚动摘要             │  ← 每积累 6 条旧对话自动压缩
├──────────────────────────────────────┤
│ 逐字层   最近 6 条对话原文               │  ← 完整细节
├──────────────────────────────────────┤
│ 参考层   原著当前章节上下文              │  ← 一致性锚点
└──────────────────────────────────────┘
```

侧边栏「记忆体」面板实时展示摘要内容与压缩进度，用户对 AI 的记忆状态一目了然。
